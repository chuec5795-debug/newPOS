Retail Point of Sale (POS) System

Complete Technical & Operational Manual (Node.js & Express Stack)

System Overview

Tun's Mart POS is a full-stack Web-Based Point of Sale system powered by a Node.js and Express backend. It provides retail operations with high-speed checkout capabilities, automated inventory tracking, real-time sales reporting, and secure role-based access control.

  • Backend Engine: Express HTTP REST API handling requests, JSON body parsing, cross-origin security, and centralized data persistence.
  • Environment Configuration: Built-in support for environment variables (.env) via dotenv to manage secret keys (e.g., GROQ_API_KEY) and application ports.
  • QR Code Receipts & Scanning: High-speed barcode decoding at checkout paired with instant Base64 dynamic QR receipt generation.
  • Role-Based Access Control (RBAC): Server-side session/token verification enforcing access levels for Administrators, Managers, and Cashiers.

Key Modules & Functions

1. Authentication & Security (/login.html)

Users authenticate using credentials checked against the database. Upon verification, the Node.js server issues a secure session token.

  • Automatic Routing: Redirects cashiers straight to /pc.html while routing higher roles to /dashboard-home.html.

2. Cashier POS Terminal (/pc.html)

Optimized primary terminal interface for high-speed cart operations.

  • Barcode Scanner Engine: Auto-detects fast input from USB/Bluetooth hardware scanners.
  • Real-Time Stock Checking: Queries Express API for item quantities, throwing immediate visual feedback if stock limits are exceeded.
  • Automated Tax & Discount Calculation: Standardized application of 10% Discount and 5% Commercial Tax.
  • Receipt Output: On payment finalization, decrements inventory stock server-side and outputs a QR code link to receipt.html.

3. Executive Dashboard (/dashboard-home.html)

Pulls live data to compute KPI cards: Total Sales Volume, Gross Profit, and Customer Traffic. Automatically highlights inventory items falling below 10 units.

4. Inventory Management (/inventory.html)

Interface for CRUD operations on store stock. Includes real-time stock indicator tags:

  • 🟢 In Stock: > 5 units
  • 🟡 Low Stock: 1–5 units
  • 🔴 Out of Stock: 0 units

5. Account Management (/accounts.html)

Admin portal to onboard new cashiers, update roles, or revoke user access.

6. Digital Receipt Generator (/receipt.html)

Renders printable and scannable transaction slips by decoding URL Base64 parameter payloads or querying transaction IDs via API.

Backend & Data Architecture

The backend application structure uses standard Express middleware (body-parser, encodeurl, content-disposition, cookie) to process incoming JSON payloads and serve client assets.

Key REST API Endpoints

  • POST /api/auth/login — Validates user credentials and generates active session identifiers.
  • GET /api/inventory — Returns array of products, prices, barcodes, and stock levels.
  • POST /api/inventory — Adds or updates product records (Admin/Manager restricted).
  • POST /api/sales/checkout — Commits cart items, calculates totals, updates inventory levels, and stores transaction records.
  • GET /api/sales/history — Fetches historical sales receipts for analytics.

Data Schemas / Models

  • systemUsers: Stores id, email, passwordHash, role, and createdAt.
  • myInventory: Stores barcode, name, price, stockQuantity, and category.
  • salesHistory: Stores transactionId, items, discountTotal, taxTotal, grandTotal, paymentMethod, and timestamp.

Deployment & Setup Instructions

1. Environment Configuration

Create a .env file in the root project directory with the following variables:

PORT=3000
GROQ_API_KEY="your key"

2. Tunneling & Port Forwarding Configuration

To support public deployment testing, dynamic QR receipts, or remote access, expose your local backend server using VS Code Port Forwarding / Dev Tunnels. Set the base dynamic URL dynamically inside your receipt payload logic:

let baseURL = "https://1w29xn1x-52649.inc1.devtunnels.ms/";
let receiptURL = baseURL + "/receipt.html?data=" + encodedReceipt;

3. Running the Server

Install package dependencies and start the Node server:

npm install
npm start

Access the app in your browser at http://localhost:3000 or via your active forwarded port URL.
